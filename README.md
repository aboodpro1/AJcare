# AJCare - Skincare Product Catalog

Interactive online skincare product directory and catalog for AJCare.

## 🌐 Live Website
Once GitHub Pages is enabled:
👉 **[https://aboodpro1.github.io/AJcare/](https://aboodpro1.github.io/AJcare/)**

## 📦 Features
- Full catalog of skincare products and verified brand directory
- Instant real-time search across products and brands
- Filter by brand with responsive sidebar & mobile selector
- Clean, responsive design optimized for mobile, tablet, and desktop
- Automatic fallback for missing images

## 🚀 GitHub Pages Setup
To publish this website on GitHub:
1. Go to repository **Settings** > **Pages** (in the left sidebar).
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Within 1-2 minutes, your website will be live at `https://aboodpro1.github.io/AJcare/`!
